## Alignment contract

### Coordinates, clocks, and supported transforms

Candidate domain contract retaining historical Alignment review evidence and the recorded revised-artifact documentary approval; empirical exercise remains pending:

1. Source frame `n` at nominal sample rate `F_in` gives source time `s = n / F_in`.
2. An independently established clip epoch/origin `e_c` gives group time `u = s + e_c`.
3. A supported group-to-aligned map is `t = a_g * u + b_g`, with `a_g > 0`; the reference group's map is identity.
4. Shared group clock means a common rate model, **not common clip starts**. Capture restarts create new epochs/segments. Timestamp metadata alone does not establish clock locking; LTC/video may actually feed a word-clock system [A5].
5. Report `map_ppm = 10^6 * (a_g - 1)` as a duration-map slope, not measured oscillator ppm.
6. For correlation with explicitly equal origins, positive lag means the target event occurs later; correction is `b = -lag / F`. Record actual origins before applying this sign convention.
7. Piecewise positive monotonic segments are permitted only after held-out validation. Gaps/jumps have explicit unsupported spans; never silently fit a smooth map through drops, duplicates, or restarts.
8. Source↔aligned inversion exists only inside supported segments. A gap has no inverse. Global edit collapse is only partially invertible and requires source-occurrence provenance; repeated clips cannot be identified by time alone.
9. Source frames, group time, aligned episode time, edited time, and export frames are separate coordinate systems. Labels and numeric editors must identify the domain.

### Estimation and confidence

PROPOSED: analyze windows throughout declared shared content, solve connected group relationships, then test held-out anchors. Correlation is a primitive [A2], not a finished podcast clock algorithm. Strong peaks can track acoustic propagation, bleed, a speaker change, or repetitive sound rather than clock error.

Include **constant and time-varying acoustic-delay negative fixtures** with independently known recorder-clock truth. Score estimated offset/rate against that truth, not peak agreement or the estimator's fitted map; apparent clock corrections caused by propagation must reject/abstain rather than pass as synchronization evidence. Freeze negative definitions, matching rules and supported strata before holdout.

Confidence must expose peak ambiguity, eligible-window span, agreement/residuals, graph-cycle consistency, connectedness, and coverage. It is not a posterior probability until calibrated. Silence, poor overlap, disconnected groups, weak peaks, and contradictory evidence require abstention. Manual anchor lists and numeric offsets/rates remain first-class, with gaps, original/source versus aligned time, audition, and undo [D1–D2, D5–D6].

Sync-lock preserves existing relationships; it does not establish initial synchronization [A6]. Manual acceptance must not manufacture evidence in unsupported regions.

### Rendering and channel integrity

- For duration map slope `a`, an expected resampling ratio is `a * F_out / F_in`, with explicit delay/epoch accounting.
- Clock speed correction changes pitch by `1/a` relative to nominal; pitch-preserving time stretch is a different operation with separate quality/phase risks [A4].
- Use the same map, segment handling, and processing for every same-group channel. Analysis proxies/downmix/gain normalization are separate and must not leak into render output.
- **Bounded provisional synthetic channel gates:** additional interchannel skew ≤1 output frame versus known relative ground truth after expected map/delay accounting; polarity inversions and channel swaps **0**; inactive-output peak ≤−80 dBFS for an isolated-channel fixture with a −1 dBFS active input and all other inputs zero. Freeze routing, window and signal conventions before holdout; these are proposals, not measured or universal guarantees.
- **Phase metric:** wrapped interchannel phase error versus known relative phase on common tones in the declared passband, after expected map/delay accounting. Alignment must calibrate and freeze frequency/window/amplitude-specific tolerances before holdout; no universal phase bound is invented, and no phase-preservation claim/gate closure is allowed without that specific calibration and result.
- Freeze spectral/channel criteria and listening rubric, excerpt strata/counts, listener counts and aggregation **before holdout**. Proposed listening budget: objectionable-artifact ratings ≤5% of the frozen per-listener excerpt-rating denominator, with ≥3 consented listeners; report counts/uncertainty and retain separate speed/pitch and spatial-image observations. Calibration may refine this proposal before holdout under the shared approval rule.
- Original source files remain immutable; derived renders are not claimed bit-identical to originals.
- One common export start/duration and boundary-rounding policy applies to all stems; pad absent spans with explicit silence.
- Apple's simple converter call does not do sample-rate conversion; evaluate the documented input-block path [A1]. Integer FIR decimation is not arbitrary dynamic clock correction [A3].
- Evaluate Apple fixed SRC and libsamplerate variable-ratio rendering first; keep soxr viable only after pinned LGPL/build/distribution clearance [A7–A8]. No linear/ZOH non-bandlimited fallback as a quality option.
