## 1. Executive summary

M1 shipped a lot of working code quickly: 46 PRs merged (median 0.63 h from open to merge), about 26k lines of source and 18k of tests, and a durability holdout of 7,190 cases with 0 failures. The core organizer was merged 8 hours in. The next 16 hours went to acceptance evidence, GUI-gated UI fixes and a two-Mac iCloud campaign (DUR-025) that went through four freezes and two failed holdouts before the user deferred it to after M4. After 24 hours, **0 of the 11 required WW issues were closed**.

The slowest factor was the GUI path: one host, coordinator-relayed lock messages (about 141 coordinator turns) and remote trial-and-error UI iteration. On top of that came three host outages only the user could fix (Automation Mode ~2 h, 1Password SSH ~2.75 h, the Computer Use escape handler). The second factor was ceremony around evidence: 16 of 46 merged PRs were process or evidence PRs, about 13k lines were docs, and the exit-record PR collected 48 commits. Cost was concentrated: every child session ran the highest-cost model with long-lived contexts (about 300k–450k input tokens per call), and the user's mid-run model-tiering directive never reached the long-lived children.

## 5. False assumptions

1. **Provider latency can be a correctness gate.** DUR-025 timed iCloud propagation as pass/fail and failed twice on settle time before being reframed as measurement, then deferred.
2. **CI on macOS 26 validates the macOS 27 runtime.** Concurrency aborts showed up only on CI, GUI behaviour only on 27.
3. **Default NSButton semantics hold on macOS 27.** `hasDestructiveAction` clears Return (4 A/B strategies to find; #114 → #122, #127).
4. **SwiftUI Table is fast enough and safe to reconfigure.** Sidebar switches took 165–177 ms (#106); conditional columns trap with a NaN width (P0 #129).
5. **`app.launch()` then `open(url)` gives one app process.** It gives two (#135, #149).
6. **XCUITest contrast audits are deterministic.** They depend on occlusion, display layout and system chrome.
7. **The fixture protocol can be frozen after running.** The retroactive `m1-freeze-1` (#62) forced relabelling of calibration runs.
8. **A model-tiering directive changes running work.** Long-lived lanes kept their model.
9. **The milestone API counter is current.** It reported 0/0 at kickoff; query issues instead.
