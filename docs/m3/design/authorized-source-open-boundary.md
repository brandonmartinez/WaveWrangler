# Authorized source-open boundary: pre-code decision

**Status: STOP / B (refusal-only), pending independent Lead and source-boundary review.** Refs #41 #40. This is a fresh-`main` interface design, not a correction of the unmerged #378/#380/#384/#394/#398 implementations. It grants no Backup content consent, does not enable a multi-source header issuer, and is not M3 acceptance. The [#41 Lead decision](https://github.com/brandonmartinez/WaveWrangler/issues/41#issuecomment-6077951041) and independent [#394](https://github.com/brandonmartinez/WaveWrangler/pull/394#issuecomment-6077643033) / [#398](https://github.com/brandonmartinez/WaveWrangler/pull/398#issuecomment-6077797375) rejections are the process gates.

Source citation prefixes such as `WWSources/`, `WWDecode/` and `WWCore/` are under `Packages/WaveWranglerKit/Sources/`; other paths are repository-relative.

## Existing boundaries, not authorization

- M3 media consent covers **the selected Primary tracks of one disposable local episode copy** for local speech/review only; it does not cover a Backup or any other recording. The M3 kickoff forbids inferring consent from an in-app default (`docs/planning/kickoffs/m3.md:27-30`; `.squad/decisions.md:327-333`). A read-only bookmark is a location/permission hint, not identity or content consent (`WWSources/DeviceAccessRecord.swift:22-42`; `WWSources/SourceIO.swift:5-29`). Confirmation of metadata identity is also not consent (`WWSources/IdentityEvidence.swift:117-134`). Organizer availability and `SourceAvailabilitySetting.on` cannot trigger a header/sample read (`WWSources/SourceAccess.swift:6-28`).
- `FileDeviceAccessStore` caches its first disk read per actor, then loads, edits and atomically replaces the JSON without a cross-instance/process transaction; a second instance can retain stale authorization or overwrite a revoke (`WWSources/DeviceAccessRecord.swift:123-137,159-224`). `SecurityScopeLedger` balances scoped starts/stops but neither requires a positive scope result nor serializes record mutation (`WWSources/SecurityScopeLedger.swift:27-63`). `EpisodeSourceInventorySurveyor` enumerates **declared** `SourceObservations.channelCount`, not physical channels, and rechecks records only for a metadata inventory (`WWAlignPipeline/EpisodeSourceAccessVerifier.swift:16-22,267-289,304-337`). Its caller-controlled document callback cannot bind an open show (`:8-16,92-112`).
- The app-owned `OpenShowSourceBinding` checks the registered `ShowDocument`, uniqueness, clean in-memory model and independently decoded exact on-disk publication, but its `current()` is an awaited readback, **not a lease** (`WaveWrangler/Alignment/OpenShowSourceBinding.swift:12-72,79-119`; `WaveWrangler/Document/ShowDocument.swift:29-59`). A revision number alone is not an identity: compare the entire `RevisionFingerprint` and publication plus the model (`WWPersistence/RevisionFingerprint.swift:5-30,42-52`). An accepted revision requires a current map content/dependency/ready key, not merely `acceptedRevision != nil` (`WWCore/EpisodeAlignment.swift:12-31`; `WWAlignPipeline/EpisodeSourceAccessVerifier.swift:193-218,299-337`).
- `SystemSourceContentIO.openForDecoding(url)` invokes `AudioFileOpenWithCallbacks` (whose parser callback can read header bytes) inside `make`, before `SourceDecoder.verifyOpened` or `CursorWorker` verifies the descriptor (`WWDecode/SystemSourceContentIO.swift:175-226`; `WWDecode/SourceDecoder.swift:119-125`; `WWDecode/DecodingCursor.swift:141-155`). A successful **post-parse** `verifyOpened` cannot undo bytes already read from the wrong object. The current gateway already uses `O_RDONLY | O_CLOEXEC | O_NOFOLLOW | O_NONBLOCK`, `F_GETFL`, `fstat`, `SF_DATALESS` refusal and read callbacks with dataless materialization OFF; retain them (`WWDecode/SystemSourceContentIO.swift:175-211,225-226,65-91`). Its `OpenedFileState` lacks a descriptor volume identity (`WWDecode/SourceContentIO.swift:57-71`).

## Conditional private seam (not enabled by this document)

The only production caller is the app's `@MainActor OpenShowSourceBinding`, captured from its actual registered `ShowDocument`; `OpenEpisodeSourceSnapshot.inventory` is only a hint. The entrypoint is `private func issueBoundedHeader(episode: EpisodeID, source: SourceID, purpose: .allLaneBacking) async throws(HeaderRefusal) -> BoundHeaderReceipt`. It accepts **IDs and a fixed purpose only**: never a URL, bookmark, grant boolean, fingerprint, revision, channel count, receipt, caller callback or supplied show model. `BoundHeaderReceipt` has an inaccessible initializer, is non-Codable and contains only show/episode/source/occurrence identity, exact show publication/digest, accepted-map content/ready key, source and grant generations, descriptor object identity, validated physical stream shape and header-budget evidence; it contains **no URL, descriptor, scope, or reusable authorization**. A later use must reissue/revalidate, not treat this receipt as permission to decode, render, cut or publish.

The entrypoint's sole source of current grant data is a WWSources package-private `FileDeviceAccessStore.withCurrentHeaderGrant(for: DeviceAccessKey, purpose: HeaderPurpose, opener: GuardedDescriptorOpener) async throws(HeaderRefusal) -> HeaderEvidence`. `GuardedDescriptorOpener` is a package-private implementation supplied **only** by WWDecode; its borrowed, non-escaping `AuthorizedDescriptorTarget` is created inside WWSources from the locked *on-disk* record and source-specific consent ledger. Only WWDecode sees the resolved URL inside that synchronous callback; no app/caller API returns it and no caller constructs a target or receipt. The source-specific ledger must contain an explicit user grant for `(showID, sourceID, purpose)`, its revocation generation and confirmed expected file identity, independently of the read-only bookmark and selected-Primary speech consent. A missing Backup grant returns `.consentMissing(source)` before any Backup open. The current episode must still contain that exact source/role/occurrence; a later relink or role change needs a new explicit grant, not a transferred one. No consent ledger or Backup grant exists on this base: **do not seed one from prior metadata, a saved URL, a caller assertion, a Primary grant or this document**.

WWSources owns the *single* device-local transaction boundary for all cooperating store instances and processes. A persistent, never-unlinked app-controlled lock inode beside the record file (opened no-follow and identity-checked) serializes **every** single/batch save, delete, show-wide delete, relink, regrant/revoke, confirmation and automatic bookmark refresh with each header lease. Acquire a process-wide FIFO waiter turn and an exclusive interprocess advisory lock on a dedicated descriptor off the cooperative executor; use nonblocking retry with cancellation/deadline and `.gateUnavailable` on starvation, not an unbounded blocking lock. Cross-process `flock` does not promise FIFO: no newly queued local reader may overtake a waiting local mutation; on cross-process contention the bounded waiter **refuses**, never claims global fairness. Keep one lock order (local queue -> interprocess gate -> record I/O -> scope -> descriptor/header); never await a main-actor, document, coordinator or caller callback while holding it, and never acquire it recursively. A canceled waiter removes its queue entry; a granted lease uses `defer` to close reader/descriptor, stop a positively started security scope and release the lock, including parser errors/cancellation/process death. A local revoke request blocks later *local* opens and asks its active reader to stop; a cross-process revoke waits its turn without a false claim that the other process sees a pending request. Both commit only after the active lease closes. Completed revocation promises zero **subsequent** reads, not retroactive erasure of bytes already read. Report cancellation/lock failure explicitly.

Under that gate, bypass the actor cache, reload the entire record/consent envelope from disk and check a durable, monotonic generation (checked overflow refuses); never authorize from `FileDeviceAccessStore.cache`, `resolvedURLs`, `latestObservation` or a preceding `await record(for:)`. Every mutation reloads and compare-and-swaps its expected row generation, preserves unrelated keys, bumps the envelope and affected grant generation, atomically writes/fsyncs file and directory, then updates any cache. A stale write/unknown schema/corrupt file/lock loss is an explicit refusal, not a merge of old grant state. Existing plain `save`/`remove*` and importer/monitor/relink paths must be routed through this boundary; in-memory stores remain test doubles, not a production positive issuer. This is serialization **only for cooperating app processes**; file-provider/OS/external changes do not take this lock.

After acquisition, resolve the *current* bookmark, require an unambiguous **positive** read-only security scope and exact confirmed baseline, fresh local regular-file/residency metadata, then hand its expected `(volume UUID, file number, size, modification time, grant generation)` to WWDecode's guarded opener. In one synchronous transaction **with no `await` between final current grant check and `O_RDONLY`**, open with `O_CLOEXEC | O_NOFOLLOW | O_NONBLOCK`, check `F_GETFL & O_ACCMODE == O_RDONLY`, `fstat` regular/non-dataless/nonempty and obtain descriptor-bound volume UUID and file number (plus `st_dev`/path `lstat` where applicable). Require exact expected object/volume and size/mtime with documented timestamp tolerance; an unavailable descriptor volume identity or changed path/object refuses **before the first parser callback**. Read-only/no-follow flags, scope, `fstat` and `verifyOpened` **after** `AudioFileOpenWithCallbacks` are not substitutes. Keep dataless materialization OFF at open and every read; failure to establish the required policy/residency is `.residencyUnverified`, not a permissive fallback. Open the parser **only on this already-checked descriptor**, never reopen by pathname. Limit the header to 1,048,576 aggregate bytes, 256 callback reads, and checked `offset + count <= 8,388,608` (anything outside refuses `.headerBudgetExceeded`); allow reads only within independently identified structural-header spans, never audio-data ranges, and refuse a parser that seeks into samples or cannot establish those spans. Check cancellation and a two-second deadline on each callback, without claiming a hard wall-time bound if a platform call itself blocks. Keep the mutation gate and scope until that bounded header inspection and reader close complete. No sample read, download or preview occurs in an organizer/header inspection; `readRawFrames` requires separate purpose-specific content authorization.

WWDecode must obtain **physical** channel count, channel layout/order, codec frame length and packet/data-byte envelope from independently cross-checked opened container/decoder facts, not the mutable `SourceObservations.channelCount` or a caller `FormatInterpretation`. Validate every mapped channel and every speaker Primary/Backup/reference against the complete physical channel range; check header layout labels/count, raw PCM bytes per frame and data size, packet count/frames-per-packet and priming/valid/remainder against reader length and file bounds. A self-consistent forged mono header wrapping what someone calls two-channel raw samples is observationally indistinguishable from mono without independent trusted format evidence: **refuse `.physicalShapeUnproven`**, do not certify completeness from the header claim alone. For finite rates, match the supported `DecodeEnvelope` integer-rate table as `Double` **before** converting to `Int` (so `1e300` refuses), and reject nonfinite/nonintegral/nonrepresentable values. Checked addition/multiplication must precede `ChunkPump`, `RawDecodeBuffer`, channel-layout allocation and `makeSink`: `priming + valid + remainder + packetSlack`, running frame positions, `packetCount * framesPerPacket`, per-frame/data offsets and `frames * channels * bytesPerSample` / memory and render limits all must fit. Refuse `.invalidFrameEnvelope` / `.invalidByteEnvelope` / `.unsupportedRate` or `.physicalShapeUnproven` with **zero sink-factory calls**. Current `DecodeEnvelope.interpret` converts an unchecked huge `Double` to `Int`; current `ChunkPump` allocates then performs unchecked additions and `SourceDecoder` calls `makeSink` first (`WWDecode/DecodeEnvelope.swift:58-62,81-92`; `WWDecode/DecodingCursor.swift:23-41`; `WWDecode/SourceDecoder.swift:123-133`; `WWDecode/SystemSourceContentIO.swift:170,292-299`). Keep existing `DecodeFailure`/typed unsupported and inconsistency cases for existing decode callers; add precise header-specific refusal cases rather than wrapping all errors as `.sinkFailed` (`WWDecode/DecodeFailure.swift:5-55`).

**Receipt is not final admission.** After *every* await, the app binding rechecks registration, unique ShowID, document URL, clean in-memory model vs verified model and exact base; independently rereads the bound show from disk and compares full `RevisionFingerprint`, publication and decoded model. It rechecks source role/occurrence, current on-disk grant/identity generation, actual physical channel coverage (including Backup/other-speaker and timed silence), accepted map **content/dependency/ready** key, and the current protection/final merged-fade and common edit/preview revision. A change or cancellation discards evidence without receipt. The final synchronous no-await main-actor check follows the last awaited read; a later render/history/preview admission must repeat currency checks in its own atomic publication boundary. This header receipt supplies source provenance and shape **only**: `CommonEditAttestation.prepare` remains refusal-only without trusted complete protection, fade, accepted-map content and atomic map/history authority (`WWCommonEdit/CommonEditPreflight.swift:211-220`; `docs/m3/ww-027-cut-policy-protocol.md:86-119`). Primary analysis or a synthetic map cannot supply Backup protection or all-lane acceptance.

## Feasibility decision and required red-first matrix

**B is the active implementation choice.** An advisory lock cannot serialize an OS security-scope revocation, provider replacement, uncoordinated writer or a user's external change; a grant can disappear after the last observation or while a descriptor is already open. Neither `startAccessingSecurityScopedResource`, `O_RDONLY`, `fstat`, `NSFileCoordinator`, a disk generation nor post-header resurvey proves the stronger invariant **"no revoked Backup header was opened/read"** against those actors. On this ownership boundary no such guarantee is established; do **not** deploy the conditional positive seam for Backups. Refuse the multi-source header issuer (`.trustedAuthorityUnavailable` / `.consentMissing`), open **zero** Backup headers and samples, keep #41/#40 open, and do not label a subset preview or edit/render as all-lane. The only path off B is a written independent proof of external revocation/ownership and a separately explicit per-source Backup grant, reviewed before any code author; otherwise a scope-changing user decision must rescope the desired behavior, not weaken the no-read rule.

Write these synthetic counterexamples **red first on the then-current code**, with deterministic barriers and exact typed refusals; no real Backup/media, model, VM, network or actual recordings are authorized here. A refusal-only baseline is expected to have zero Backup gateway opens; a future *positive fixture* uses synthetic per-source grants solely to exercise the guarded seam.

| Synthetic control | Required observable outcome |
| --- | --- |
| Two independent `FileDeviceAccessStore` instances, then a **separate process** revokes/relinks B after the last await before B open | Current disk generation wins; `.consentMissing`/`.grantChanged`, **zero B `open` and parser reads**; no stale-cache fallback, no lost update when another source is saved. |
| Revoke/relink while B header lease is active; separately cancel a queued waiter and an active parser | Mutation waits for close; canceled reader emits no later read/receipt; scope and lock release once; a second waiter progresses or times out explicitly, without deadlock or local writer starvation. |
| Prime one instance's cache, then mutate B from a different instance/process and perform an unrelated saved-record update | Current B grant/identity and monotonic disk generation survive; stale cached B is refused, not resurrected or overwritten; zero B opens after committed revoke. |
| Swap B pathname/symlink/alias or change descriptor identity between preflight and open | `.sourceIdentityMismatch` / `.physicalIdentityUnknown`, **zero parser callbacks** and no alternate-path reopen; volume+file identity, mode and residency are checked on the actual descriptor. |
| Replace the disk show with equal revision/different bytes, or edit the in-memory show, Save As, close or change registered document | `.changedDuringVerification`, no receipt even if metadata inventory still matches; accepted-map content/ready key and source/role/protection changes similarly refuse. |
| Claim one channel in `SourceObservations` for a two-channel opened stream, or assert two channels over coherent mono/ambiguous layout | `.physicalShapeUnproven` / `.channelMismatch`, no all-lane receipt; every physical channel has exactly its required lane and independent protection, not a guessed silent lane. |
| `validFrames = Int64.max, priming = 1`; packet/frame or frame/channel/byte overflow; finite `sampleRate = 1e300` | Typed `.invalidFrameEnvelope` / `.invalidByteEnvelope` / `.unsupportedRate` **before allocation and with zero `makeSink` calls**; no trap or generic sink error. |
| Cancel before gate, after grant check, in bounded header callback, or after the last awaited document/record check | `.cancelled`, zero *new* opens after pre-open cancellation, no receipt, balanced scope/descriptor/gate; a completed external revocation cannot be reported as a valid new grant. |
| Header callbacks exceed 1,048,576 bytes, 256 reads or the 8,388,608-byte offset envelope | `.headerBudgetExceeded`, reader closed, no sample reads or receipt, gate and scope released. |
| A container/parser requests audio-data bytes while supposedly probing structural headers | `.sampleReadAttempt`, **zero sample bytes delivered**; no receipt and all leased resources released. |
