# Product screenshots

These are native WaveWrangler window and sheet captures from a macOS VM,
using generated recordings and music with seeded fictional transcripts.
The waveforms illustrate editing controls, not measured speech or alignment
accuracy. No personal recordings, downloaded speech or recognition model
were used.

Reproduce the eight PNGs with the opt-in
[`DocumentationScreenshotUITests`](../../../WaveWranglerUITests/DocumentationScreenshotUITests.swift)
and the [VM capture procedure](../../engineering/gui-testing.md#reproduce-documentation-screenshots).
Inspect every image and keep its semantic filename when refreshing it.
Screenshot capture is not audio-quality, export or release qualification.
