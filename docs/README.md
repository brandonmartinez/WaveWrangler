# WaveWrangler documentation

WaveWrangler brings separate podcast recordings into a shared timeline for
reviewed alignment, nondestructive editing, mixing, and whole-episode export.

## Using the app

Start with [Getting started](product/getting-started.md), or browse the
[complete user guide](product/README.md).

| Task | Guide |
| --- | --- |
| Organize shows, episodes, speakers, and source access | [Library and recordings](product/library-and-recordings.md) |
| Review automatic timing or align manually | [Alignment](product/alignment.md) |
| Transcribe, review fillers, cut, or mute a speaker | [Transcription and editing](product/transcription-and-editing.md) |
| Add music, insert an intro, and shape fades | [Audio Clips](product/audio-clips.md) |
| Set gain, use Audio Units, and hear production | [Mixer](product/mixer.md) |
| Set boundaries, metadata, artwork, and delivery formats | [Export](product/export.md) |
| Understand save status, recovery, and moved media | [Saving and recovery](product/saving-and-recovery.md) |
| Work from the keyboard | [Keyboard shortcuts](product/keyboard-shortcuts.md) |
