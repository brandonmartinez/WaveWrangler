# Optional local MCP configuration

The repository's Squad agent, skills, roster, casting and contributor context work without enabling either example MCP server.
Live `.mcp.json` and `.copilot/mcp-config.json` are machine-local and ignored.

The adjacent example and root `.mcp.json.example` preserve the installer examples, not validated production integrations.
They do not run automatically. Before opting in, verify the package/server and pin an approved exact version; `@insider` is a floating tag.
Retain the user's configured registries, supply credentials outside Git and obtain approval before installing or launching new software.
Do not put literal credentials into repository configuration.

Operational work follows `docs/planning/milestone-runbook.md`, not a broad autonomous watcher.
