## Accepted policies and research boundaries

1. **Q01 — Library, references, cloud projects, saves.** One durable project per podcast/show, with multiple episodes and a first-class project library/sidebar. Reference recordings in place; copying media into portable bundles is deferred. Cloud-hosted canonical project documents are MVP, including user-chosen OneDrive/iCloud/Dropbox locations subject to safeguards and measured provider behavior. Autosave is ON by default, configurable/off, with explicit Save always available. User suggestion: “Potentially in memory with periodic saves instead of having a constant lock to the project file. Projects would be relatively light comparatively ... Maybe having an auto save option ... user configurable”. In-memory state, lightweight snapshots, coordinated saves and cadence are research candidates, not selected architecture. Investigate consistency, conflicts/recovery, offline/cancellation and unknown/failure states. Scoped access permission is distinct from a long-lived POSIX/database lock; no file/package/SQLite choice guarantees provider atomicity.
2. **Q02 — Platform and language.** Evaluate macOS 26 and newer on Apple silicon only; Intel and non-English languages are deferred. SpeechTranscriber becomes an eligible baseline candidate, not automatically chosen or validated. Compare native Speech and local Whisper under timing, offline, provisioning/download and update constraints. No external claim about Intel decline is accepted.
3. **Q03 — Distribution.** Signed/notarized direct download first; App Store first launch deferred. Signing, hardened runtime, permissions/privacy and artifact-specific dependency/model redistribution clearance remain gates. No legal/paid budget or license assurance is approved.
4. **Q04 — Research permission and consent.** Bounded synthetic experiments and disposable research prototypes are authorized for the next research phase, not execution in this integration task. No production app, user-recording processing, dependency install or model download is authorized. Each exact model download requires separate approval after its source, license and size are known. Native speech asset provisioning/network traffic may require consent. Representative-recording rights/fixtures and provider/network/cloud-writing trials remain separately scoped and unapproved.
5. **Q05 — Edit modes.** Synchronized time-shortening is MVP. Exact default: “Shorten when safe and by default, but allow the user to edit that point and choose a different method”. Every human-accepted cut uses one common episode edit map on every previewed/exported track, never independent speaker ripple. Per-cut modes are editable/reversible; timing-preserving speaker lift is an alternative, especially during another speaker’s overlap. Overrides cannot remove protected, meaningful or other speech; uncertain cases remain review/manual/abstain. Preserve undo/history, time domains/partial inverses/source occurrences, crossfades and preview/export equality; no automatic filler acceptance.
6. **Q06 — DAW-neutral handoff and format.** User: “offer an export option that treats each speaker's audio track as a 0-aligned stem ... cross compatible with any DAW”. Broad WAV compatibility is a validation goal, not a universal fact. Export one cleaned zero-origin stem per speaker with identical common time map/rate/duration/rounded frame boundaries and silence padding. Include a documented editable cut record with source references, decisions and asset requirements sufficient for inspection/regeneration with explicitly available assets; stems alone cannot restore removed material. No required REAPER/native adapter or forced portable media copies. Default 48 kHz/24-bit PCM WAV, configurable; offer feasible detected source settings, preferring 48 kHz, with coherent common-rate output for mixed inputs. AAF/OMF/RPP may be optional later research. Human/machine record edits, actual integer frame endpoints and restoration/regeneration need validation.
7. **Q07 — Reference and gates.** Initial performance reference is 16 GB; evaluate 8 GB later. This is not a proven minimum-memory support claim. Provisional numerical quality/accessibility gates are approved goals, calibrated before holdout with explicit approval for weaker gates. Include cloud canonical projects and common-map shortening in coverage.
8. **Q08 — Approval status.** Updated direction is approved for bounded future research/design and the Q04 synthetic/prototype scope. Q01–Q10 are answered; research authorization is no longer pending. Production milestones, recording access, installs and exact downloads remain separately gated. Format/lifecycle/exact model/measurement/provider guarantees remain unknown until evidence. This integration turn executes none of the newly authorized research.
9. **Q09 — Imports and source downloads.** Common macOS audio formats are MVP subject to validation. PCM WAV/BWF, AIFF, CAF, AAC/M4A, MP3 and optionally supported FLAC are candidate containers/codecs, not promised support. Address priming/padding/time mapping, variable-rate/bit-depth/channel metadata, corruption/unsupported errors and decoder build licenses; prefer native decoding if evidence supports it, without custom training. Automatic source downloads are user-configurable, ON by default with clear accessible status and an option to disable, superseding a product-level no-hydration policy. Validate progress/unknown/offline/cancel/retry, native provider coordination and immutable originals; no fake generic provider classifier. This future policy does not authorize actual sample access/hydration or override exact-model consent. Metadata-only default-OFF fixture trials must be labeled as such.
10. **Q10 — Native lifecycle.** Compare AppKit NSDocument + SwiftUI views with the SwiftUI document lifecycle, prioritizing native behavior, cloud-safe saving, configurable autosave and recovery. Recommend from evidence. No framework, package or JSON/SQLite format is adopted.
