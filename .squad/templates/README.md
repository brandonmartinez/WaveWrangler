# Installed Squad reference templates

These files are the repository's portable Squad scaffolding, not authority to install tools, start background watchers or run every workflow.
The active operating contract is `docs/planning/milestone-runbook.md` and the user's named milestone kickoff.
Legacy example branching, broad autonomous execution and placeholder integrations do not override that contract.

The four matching workflow templates are intentionally synchronized to WaveWrangler's manual-only/advisory workflows.
Preserve that project policy during upgrades; do not restore stock automatic issue/PR/push triggers.
MCP examples require explicit verification, version pinning and opt-in, with credentials outside Git.
